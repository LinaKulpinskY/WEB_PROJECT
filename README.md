# Анализатор безопасности веб-сайтов

Веб-приложение для анализа безопасности веб-сайтов с интегрированным AI-помощником.

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск

Запустите приложение:
```bash
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Структура проекта

- `app.py` - Основной Flask-сервер
- `assistant.py` - Логика AI-помощника (используется в app.py)
- `templates/dashboard.html` - Главная страница с анализом безопасности
- `templates/chat.html` - Страница чата с AI-помощником
- `requirements.txt` - Зависимости проекта

## Функциональность

1. **Главная страница** (`/`) - Анализатор безопасности веб-сайтов
   - Информация о проекте
   - Анализ безопасности веб-сайта
   - Методы самостоятельной проверки
   - Настройка DNS-серверов

2. **Чат с AI** (`/chat`) - Интерактивный чат с AI-помощником по кибербезопасности
   - Задавайте вопросы о безопасности веб-сайтов
   - Получайте практические рекомендации

## API

### POST /api/chat

Отправка сообщения в чат с AI-помощником.

**Запрос:**
```json
{
    "message": "Как защитить сайт от XSS атак?",
    "session_id": "session_123"
}
```

**Ответ:**
```json
{
    "response": "Ответ AI-помощника..."
}
```
